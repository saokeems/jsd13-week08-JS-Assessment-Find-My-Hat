# Find My Hat — Development Process

## 📋 1. ศึกษาโจทย์และวางแผน

- ดูตัวอย่างการทำงานของตัวเกมก่อน แล้วกลับมาดู **Criteria** ที่โจทย์ต้องการ
- จดลงสมุดสรุปว่าเกมทำงานอย่างไร ควรมีฟังก์ชันอะไรบ้าง — ลิสต์ออกมาเท่าที่คิดออก
- เปิด docs หรือตัวงานเก่า เพื่อศึกษาโครงสร้างการเขียนเบื้องต้น

## 🛠️ 2. เริ่มโครงสร้างโปรเจกต์

- เขียนตัวแปรที่ลิสต์ไว้เป็นค่าเริ่มต้น
- สร้าง `class` พร้อม `method` และ `constructor` ตาม Criteria ที่กำหนดไว้ก่อน (ยังไม่ลงรายละเอียด)

## ⌨️ 3. รับคำสั่งจากผู้เล่น

- เขียนฟังก์ชันรับ input:
  - `askForCommand()` — รับคำสั่งจากผู้เล่น
  - `handleCommand()` — จัดการคำสั่งที่รับเข้ามา
- ทดลองรันเพื่อตรวจสอบว่าทำงานได้ตามต้องการ

## 🌐 4. สร้าง Field

- เขียนฟังก์ชัน `randomField()`:
  - เริ่มจากแสดง field เป็น **2 มิติ** ตามที่กำหนด
  - สุ่มตำแหน่ง **หลุม** และ **หมวก**
  - ตำแหน่ง player เริ่มที่ `(0,0)` — ยังไม่สุ่มในขั้นตอนนี้

## 🏃 5. การเคลื่อนที่ของ Player

- กลับไปเขียน method move ต่างๆ ภายใน `class` field
- ทดสอบว่า player เคลื่อนที่ได้ถูกต้องตามที่ต้องการ

## ✅ 6. เงื่อนไขการแพ้–ชนะ

- เขียนฟังก์ชัน `checkField()` เพื่อกำหนดเงื่อนไขผลแพ้/ชนะของเกม
- เมื่อได้ version ที่สุ่มหลุม + หมวก และตรง Criteria บางส่วนแล้ว → **บันทึก version เอาไว้ก่อน**

## 🎨 7. ปรับปรุงเพิ่มเติม

- เพิ่ม logic ฝั่ง player: **สุ่มตำแหน่งเริ่มต้น** แทนการ fix ที่ `(0,0)`
- เพิ่ม UI เล็กน้อยตอนเริ่มเกม
