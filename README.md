# Find My Hat — Development Process

## 📋 1. ศึกษาโจทย์และวางแผน

- ดูตัวอย่างการทำงานของตัวเกมก่อน แล้วกลับมาดู **Criteria** ที่โจทย์ต้องการ
- จดลงสมุดสรุปว่าเกมทำงานอย่างไร ควรมีฟังก์ชันอะไรบ้าง — ลิสต์ออกมาเท่าที่คิดออก
- เปิด docs หรือตัวงานเก่า เพื่อศึกษาโครงสร้างการเขียนเบื้องต้น

## 🛠️ 2. เริ่มโครงสร้างโปรเจกต์

- เขียนตัวแปรที่ลิสต์ไว้เป็นค่าเริ่มต้น
- สร้าง `class` พร้อม `method` และ `constructor` ตาม Criteria ที่กำหนดไว้ก่อน (ยังไม่ลงรายละเอียด)

## ⌨️ 3. รับคำสั่งจากผู้เล่น

- เขียนฟังก์ชันรับ input:
  - `askForCommand()` — รับคำสั่งจากผู้เล่น
  - `handleCommand()` — จัดการคำสั่งที่รับเข้ามา
- ทดลองรันเพื่อตรวจสอบว่าทำงานได้ตามต้องการ

## 🌐 4. สร้าง Field

- เขียนฟังก์ชัน `randomField()`:
  - เริ่มจากแสดง field เป็น **2 มิติ** ตามที่กำหนด
  - สุ่มตำแหน่ง **หลุม** และ **หมวก**
  - ตำแหน่ง player เริ่มที่ `(0,0)` — ยังไม่สุ่มในขั้นตอนนี้

## 🏃 5. การเคลื่อนที่ของ Player

- กลับไปเขียน method move ต่างๆ ภายใน `class` field
- ทดสอบว่า player เคลื่อนที่ได้ถูกต้องตามที่ต้องการ

## ✅ 6. เงื่อนไขการแพ้–ชนะ

- เขียนฟังก์ชัน `checkField()` เพื่อกำหนดเงื่อนไขผลแพ้/ชนะของเกม
- เมื่อได้ version ที่สุ่มหลุม + หมวก และตรง Criteria บางส่วนแล้ว → **บันทึก version เอาไว้ก่อน**

## 🎨 7. ปรับปรุงเพิ่มเติม

- เพิ่ม logic ฝั่ง player: **สุ่มตำแหน่งเริ่มต้น** แทนการ fix ที่ `(0,0)`
- เพิ่ม UI เล็กน้อยตอนเริ่มเกม

=========================================================================================================================================
1. ขั้นแรกตัวผมเริ่มจากการดูตัวอย่างของตัวเกม ว่ามันทำงานยังไง และกลับมาดู Criteria ที่โจทย์ต้องการ
2. กลับมาเขียน/จด ลงสมุดว่ามันทำงานยังไง ควรมีฟังก์ชันอะไรบ้าง ลิสต์ออกมาเท่าที่คิดออก
3. หลังจากนั้นก็กลับไปเปิด docs หรือ ตัวงานเก่าเพื่อศึกษาโครงสร้างการเขียนเบื้องต้น
4. เริ่มลงมือทำจากขั้นแรกเริ่มก็เขียนตัวแปรที่ลิสต์ไว้มาเป็นค่าเริ่มต้น และสร้าง class พร้อม method และ constructor ตาม Criteria ที่กำหนดมาเบื้องต้นเอาไว้ก่อน โดยที่ยังไม่ได้เขียนรายละเอียดอะไรมาก
5. หลังจากนั้นก็เริ่มเขียนฟังก์ชันให้มันรับคำสั่งที่เราจะป้อนเข้าไปก่อน โดยเริ่มจากตัว askForCommand() และไป handleCommand() จากนั้นก็ทดลองรันว่ามันทำงานได้เบื้องต้นที่ต้องการแล้วยัง
6. เมื่อได้ 2 ฟังก์ชันข้างบน ก็เริ่มเขียน ฟังก์ชัน randomField โดยเริ่มจากการลองเขียนให้มันแสดงเป็น field 2 มิติ ตามที่กำหนดไว้ก่อนเมื่อได้แล้วก็เริ่มลงเขียนรายละเอียด การสุ่มตำแหน่งหลุม และ ตำแหน่งหมวก โดยที่ตำแหน่งของ player จะยังเริ่มที่ 0,0 ไม่ได้ทำการสุ่ม
7. หลังจากได้ field ก็กลับไปเขียน method move ต่างๆ ภายใน class field อีกครั้ง หลังจากเขียนเสร็จก็ลองทดสอบว่างมันทำงานหรือเคลื่อนที่ตามที่ต้องการแล้วหรือยัง
8. เมื่อได้ตามที่ต้องก็ไปเขียนเช็คเงื่อนไขเป็น ฟังก์ชัน checkField เพื่อกำหนดเงื่อนไขผลแพ้ชนะของเกม
9. พอได้ version ที่สุ่มตำแหน่งหลุม หมวก โดยไม่สุ่มตำแหน่ง และทำตรงเงื่อนไข Criteria บ้างส่วนแล้ว ก็บันทึก version เอาไว้ก่อน
10. หลังจากนั้นก็เริ่มปรับแก้เพิ่ม logic ในส่วนของ player ให้มันสุ่มตำแหน่งเริ่มต้นด้วยเช่น และเพิ่ม ui ตอนเริ่มเกมเล็กน้อย
